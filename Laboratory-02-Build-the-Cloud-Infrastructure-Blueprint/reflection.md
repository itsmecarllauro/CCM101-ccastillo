# Reflection

**1. Which cloud infrastructure component do you think is the most important? Why?**

I think compute resources are the most important because they are responsible for running applications and processing data. Without compute power, storage would only hold data, and networking would have nothing to connect to. Compute resources help make cloud services work.

**2. How does Linux support cloud computing?**

Linux supports cloud computing because it is lightweight, stable, and free to use. Many cloud servers use Linux because it is reliable and easy to manage. It also allows users to control system resources through the terminal, install software, and automate tasks.

**3. Why is technical documentation important before deploying infrastructure?**

Technical documentation is important because it helps engineers know what resources are available and what has already been set up. It also records the decisions made during the setup. Without proper documentation, mistakes can happen and it can be harder to troubleshoot problems or work with a team.
