# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the access and permissions they need to do their work. This is important in cloud computing because it helps prevent unauthorized access and reduces the risk of security problems.

## Attack Surface

The attack surface refers to all the possible ways an attacker can access or attack a virtual machine. Open ports, running services, and unnecessary applications can increase the attack surface, so they should be managed properly to keep the server secure.

## Default Deny Policy

The Default Deny Policy means blocking all incoming network traffic unless it is specifically allowed. I think this is safer because it prevents unwanted connections and allows only trusted services, such as SSH and the web application, to receive traffic.
