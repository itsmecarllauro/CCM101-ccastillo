# Automation Research

## Bash Script

A Bash script is a file that contains commands that Linux can run automatically. The `#!/bin/bash` line at the top tells the system to use Bash to run the script. It helps execute commands in the correct way.

## Variables

Variables store information, such as folder paths, so we do not need to type the same values repeatedly. For example, `$BACKUP_DIR` stores the name of the folder where backup files will be saved. Using variables makes the script easier to read, update, and manage.

## Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts at a specific time. It is useful in cloud operations because it can automatically perform regular tasks, such as backing up important files, without someone needing to run them manually. This saves time and reduces the chance of human error.
