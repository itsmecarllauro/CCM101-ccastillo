## Skills Learned
In this activity, I learned how to create a Linux user and give the user sudo access. I also practiced using Git to clone my GitHub repository and navigate through the project files using the terminal.

I learned how to deploy MinIO using Docker and configure it using environment variables. I also learned that port 9000 is used for the MinIO service while port 9001 is used for the MinIO web console.

I also experienced a Docker permission error when I tried to run Docker without `sudo`. This helped me understand that my current user does not have direct permission to access the Docker socket, so I used `sudo docker` to run the Docker commands.

Overall, this activity gave me more experience with Ubuntu, Git, Docker, MinIO, and cloud object storage.
