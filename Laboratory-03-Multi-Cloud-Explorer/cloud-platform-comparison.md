## Guide Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of services, with over 200 tools built up since 2006, giving it the largest market share and most extensive catalog.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure best integrates with Microsoft technologies since it connects natively with Active Directory, Microsoft 365, and Windows Server.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform is strongest in AI and Kubernetes, since Google created Kubernetes and offers GKE plus strong AI and ML tools like Vertex AI.

**4. Which cloud platform would you personally choose and why?**
I would personally choose AWS because it offers many different services and is useful for different types of projects. I also like that it can support both small startups and large companies. It has services for computing, storage, databases, networking, and many other needs. I think AWS would give me more options to learn and use in future projects.
