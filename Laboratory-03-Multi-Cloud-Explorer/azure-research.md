# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud platform launched in 2010, known for deep integration with Microsoft's enterprise software ecosystem.

## Global Infrastructure
Azure operates more than 60 regions worldwide, more than AWS and Google combined.

## Cloud Management Console
Azure Portal — a unified web-based dashboard for managing Azure resources, subscriptions, and services.

## Four (4) Core Services
1. **Azure Virtual Machines** — compute
2. **Azure Blob Storage** — object storage
3. **Azure Virtual Network (VNet)** — networking
4. **Microsoft Entra ID** — identity and access management

## Three (3) Advantages
1. Seamless integration with Microsoft 365, Active Directory, and Windows Server
2. Strong hybrid cloud support through Azure Arc and Azure Stack
3. Wide enterprise adoption among Microsoft-based organizations

## Typical Enterprise Use Cases
- Hybrid cloud deployments for organizations with on-premises Windows infrastructure
- Enterprise identity and access management via Active Directory integration
- Business application hosting (SAP, Dynamics 365)
