# Reflection

**1. Which cloud platform impressed you the most?**
The cloud platform that impressed me the most is AWS. I like that it offers many different services for computing, storage, databases, networking, and other cloud needs. It also provides flexible options for both small and large organizations.

**2. What similarities exist among AWS, Azure, and GCP?**
AWS, Azure, and GCP all provide similar basic cloud services. They all offer virtual machines, storage, databases, networking, identity management, and Kubernetes services. The main difference is how each platform names and provides these services.

**3. How do business requirements influence cloud platform selection?**
Business requirements are important when choosing a cloud platform because every organization has different needs. A company using Microsoft products may prefer Azure, while an AI focused company may prefer GCP. Cost, performance, security, scalability, and available services should also be considered.

**4. What did you learn from acting as a Cloud Solutions Consultant?**
I learned that choosing a cloud platform is not simply about picking the most popular provider. A Cloud Solutions Consultant needs to understand the organization's goals, budget, existing technology, and future plans. I also learned how to compare different cloud services and recommend the platform that best fits the situation.

**5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?**
My GitHub Cloud Computing Portfolio improved because I was able to document my cloud investigations, comparisons, and recommendations. It now shows my understanding of AWS, Azure, and GCP and how they can be used for different situations. I think this makes my portfolio more useful because it shows both my technical knowledge and my ability to make practical cloud decisions.
