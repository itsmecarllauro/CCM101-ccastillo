# AWS Research

## Brief Overview
Amazon Web Services (AWS), launched in 2006, is the world's largest cloud provider, offering over 200 fully featured services from data centers globally.

## Global Infrastructure
The AWS Cloud spans 123 Availability Zones within 39 Geographic Regions, with regions across North America, South America, Europe, China, Asia Pacific, South Africa, and the Middle East.

## Cloud Management Console
AWS Management Console — a web-based interface for managing all AWS services, resources, billing, and account settings.

## Four (4) Core Services
1. **Amazon EC2** — virtual servers/compute
2. **Amazon S3** — object storage
3. **Amazon VPC** — networking
4. **AWS IAM** — identity and access management

## Three (3) Advantages
1. Broadest range of services of any cloud provider
2. Largest global infrastructure footprint
3. Mature ecosystem with extensive third-party integrations

## Typical Enterprise Use Cases
- Hosting scalable web applications and APIs
- Big data analytics and data lakes
- Disaster recovery and backup solutions
